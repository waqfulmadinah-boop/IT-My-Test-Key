# IME web assets

This folder is the offline copy of the web keyboard that the Android IME loads.

- Generated by `npm run build:ime` (Vite `--mode ime` + `scripts/sync-ime-assets.mjs`).
- The script mirrors `dist/` here and keeps this README file.
- Do not edit the generated files by hand; they are overwritten on every build.
- Loaded through `WebViewAssetLoader` at
  `https://appassets.androidplatform.net/assets/www/index.html?ime=1`
  (see `KeyboardImeService.kt`), which is why Vite uses `base: './'` in IME mode.

Note: committed text is sent to the editor one code unit at a time from the web UI.
Combining marks and ZWJ sequences therefore rely on the host editor's own
composition handling; use the sub-tab panels for conjuncts and harakat.
